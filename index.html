This fixes the problem where menu updates only appear on your device. Once configured, all visitors worldwide see your latest menu when you add, edit, or delete items.

📋 How to set up (free, 2 minutes): 1. Go to jsonbin.io → Sign up free
2. Click + Create Bin → paste [] as content → Save
3. Copy the Bin ID from the URL (looks like 64abc123...)
4. Go to API Keys tab → copy your Master Key or create an Access Key
5. Paste both below and click Save

⚠ Security Note

Your API key is stored in this browser's localStorage and is only used to save the menu. Do not share your API key with anyone. Visitors only read the menu — they cannot modify it.

Our Story

A Passion for
Nigerian Cuisine

Founded in 2006, Velour was born from a singular vision — to celebrate Nigeria's extraordinary culinary heritage in an atmosphere of refined elegance. From the smoky richness of suya to the delicate layers of egusi, every dish is a tribute to our roots.

We partner with local farmers, spice traders, and artisan producers across Nigeria to source only the finest, freshest ingredients — honouring tradition while embracing modern technique.
